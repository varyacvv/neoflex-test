## Деплой

Приложение развёрнуто на Vercel: <https://neoflex-test-tau.vercel.app/>

## Стек

React · CSS · TypeScript · React Router

## Структура

```text
src/
├── components/   Header, Footer, ProductCard, ProductList, CartItem,
│                 CartSummary, ProductModal, Modal, Icons
├── pages/        HomePage, CartPage, CheckoutPage
├── context/      корзина
├── i18n/         RU/EN
├── data/         массив товаров
├── types/        Product, CartItemType
└── utils/        formatPrice
```

## Что реализовано

1. **Каталог**: 9 товаров из массива, две категории: наушники и беспроводные наушники.
2. **Карточка товара**: картинка, название, цена (старая зачёркнута), рейтинг, кнопка «Купить».
3. **Корзина**: список товаров, изменение количества (+ / −), удаление, пересчёт суммы. Сохраняется в sessionStorage.
4. **Счётчик корзины**: растёт при добавлении товара, отображается в шапке.
5. **Модалка товара:** открывается по клику на картинку, показывает описание, цену и кнопку «Купить».
6. **Оформление заказа**: форма с валидацией (имя, телефон, email, адрес, оплата). После оплаты корзина очищается.
7. **Мультиязычность**: переключатель Рус / Eng в футере, выбор сохраняется в localStorage.
8. **Адаптивность**: 3 / 2 / 1 карточки в ряд, адаптивные хедер, футер и корзина.
9. **Hover-эффекты:** на логотипе, иконках, ссылках, кнопках.
